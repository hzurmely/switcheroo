Network averages (clean)

Raw data vs clean data

Switcheroo measures the network you are on every 30 seconds and the other one every 4 minutes, so the networks end up with different numbers of samples. Python preprocesses the data (types, formats, duplicates, missing values, inconsistencies, outliers, encoding, normalization). Then it looks at the gap: if it is small nothing is done, if it is moderate SMOTE adds rows to the smaller network, and if it is large SMOTEENN is used. Real rows are never thrown away just to even out the counts.

    Settings

    General

    Updates

    Version

    When on, Switcheroo checks when it starts (including when it starts with Windows) and every few hours, and installs a downloaded update the next time you quit. When off, it only checks when you press the button.

    Startup
    What is measured

    Every check saves: download speed, latency, the slowest ping, jitter (how steady the pings are), packet loss, signal strength, link speed, channel, radio type, and every time Windows failed to join a network. Nothing leaves this PC.

    Households

    Auto detect

    Networks are paired by name, like Home and Home_5G or Casa-2.4GHz and Casa-5GHz.

    Game mode

    Common games are detected automatically. Game mode only pings, so it adds no lag, and it never switches in the middle of a match. Game mode only works while switching is on.

    Check game detection

    Open your game, then press Scan. It shows what Switcheroo sees running.

    Saved data

    When the folder passes the limit, the oldest days are deleted until it is back under 80 percent. Their totals are kept, so lifetime averages stay correct.
